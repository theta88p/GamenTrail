# GamenTrail
## 動作環境
* Windows10以降のOS

* .NET10 デスクトップランタイム <https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0>

## 使い方

1. 録画対象を選ぶ
2. 音声とコーデックを選ぶ
3. コンテナと保存先を選ぶ
4. 録画開始

## 注意点

* 録画対象がウィンドウの場合、通常は選択ウィンドウの上に重なった
ウィンドウは録画されませんが、「手前に重なるウィンドウも録画する」をチェックすると録画できるようになります。
その場合、範囲録画と同じ扱いになるので録画中にウィンドウを動かしても範囲が追従されません。

* 録音方法は録画対象がウィンドウで「画面から選択」した場合自動的に特定のアプリになります。
